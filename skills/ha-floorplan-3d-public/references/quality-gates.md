# Quality gates

- input source and license recorded;
- no real-home media or metadata;
- backup checksum matches source;
- units, orientation, camera and crop fixed;
- object names and manifest keys stable;
- walls, doors, furniture and device anchors pass geometry checks;
- fixed baseline renders compared;
- overlays align at desktop and mobile sizes;
- staged UI loads with missing-asset fallback;
- no uncontrolled animation or per-frame full rebuild;
- public export contains only synthetic assets.
