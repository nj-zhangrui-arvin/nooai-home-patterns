# Privacy model

## 公开数据必须满足

- 只使用合成人物、房间、实体和时间序列；
- 主机使用 `example.com` 或 `.example`；
- IP 使用文档专用地址段或占位符；
- 设备标识使用 `<DEVICE_ID>`、`<MAC_ADDRESS>`；
- 路径使用 `/path/to/project`；
- 图片只用合成或明确许可素材，并绑定路径、SHA-256、来源、许可证、可见内容复核和元数据清理记录。

## 永不导出

- 私有仓库历史；
- HA 生产配置和 `.storage`；
- 备份、数据库、日志、浏览器产物；
- 真实 CAD、照片、定位锚点和路线；
- 真实网络、设备、人物和账号信息。

隐私扫描只是门禁之一，不能替代人工审查。
