# Release checklist

- [x] 已选择 MIT License；
- [ ] 只复制 `open-source/`；
- [ ] 隐私门禁通过；
- [ ] 单元测试通过；
- [ ] 四个 Skill 验证通过；
- [ ] 工作树、暂存区和 commit message 门禁通过；
- [ ] 新公开仓库的 reachable history 与 unreachable objects 门禁通过；
- [ ] 作者/提交者姓名、邮箱和签名身份是明确批准的公开身份；
- [ ] 可选外部扫描器的运行或跳过状态已记录；
- [ ] 媒体为合成或许可素材，并由精确路径、SHA-256、来源、许可证和元数据复核清单批准；
- [ ] 第三方 NOTICE 完整；
- [ ] 新建空 Git 仓库，不继承私有历史；
- [ ] 提交作者使用愿意公开的身份；
- [ ] 人工浏览所有文件后再发布。
